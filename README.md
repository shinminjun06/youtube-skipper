# Block Blast Advisor v1.2.0

Android 11+용 **하이라이트 추천 전용** Block Blast Classic 보조 앱입니다. 블록은 사용자가 직접 드래그합니다. 앱은 게임 터치, 자동 스와이프, 자동 드롭을 하지 않습니다.

이 프로젝트는 `blockblast-auto-build` 브랜치에 있습니다. `main` 브랜치는 변경하지 않습니다.

## 사용법

1. [GitHub Actions 빌드](https://github.com/shinminjun06/youtube-skipper/actions?query=branch%3Ablockblast-auto-build)에서 **BlockBlastAdvisor-apk** 아티팩트 ZIP을 내려받고 APK를 설치합니다.
2. 앱에서 접근성 서비스를 허용합니다. 접근성 권한은 떠 있는 안내 표시와 게임 창 전환 감지에 사용되며 **제스처 수행 권한은 꺼져 있습니다**.
3. **전체 화면 공유 시작**에 동의하고 세로 화면의 Block Blast Classic을 엽니다.
4. 원하는 곳으로 끌어 움직일 수 있는 **▶ 추천 시작** 버튼을 누릅니다.
5. 상태 창에 표시되는 **n번 블록**을 초록색 사각 테두리 위치에 직접 놓습니다. 수동 배치를 인식하면 다음 추천이 자동 갱신됩니다.
6. 콤보 입력은 필요하지 않습니다. 게임에서 **COMBO 숫자가 잠깐 표시될 때** 기기 내 OCR로 읽고, 평소에는 확인된 수동 배치·줄 삭제를 이용해 이어서 추적합니다.

## v1.2.0 개선사항

- **콤보 숫자 수동 입력 버튼 제거**: 줄 삭제 시 나타나는 `COMBO 43` 같은 명시적인 숫자만 오프라인 OCR로 인식하고 계산기에 반영합니다. 단독 점수(`86964`)는 콤보로 해석하지 않습니다.
- **탐색 안정성 유지**: OCR 실패나 콤보 표시가 없는 동안은 최근 수동 설치와 줄 삭제에서 추론한 상태를 사용합니다. 처음부터 진행 중이던 게임인데 아직 COMBO 표시를 관찰하지 못했다면 추정 콤보는 실제보다 낮을 수 있습니다.
- **별도 외부 전송 없음**: 텍스트 인식 모델을 APK에 포함하므로 앱에서 인터넷 다운로드 없이 작동합니다. 이를 위해 설치 용량은 증가할 수 있습니다.


- 자동 드래그, 보정, 놓기, 조작용 접근성 제스처를 제거하고 **추천 전용 UI**로 복귀했습니다. 손으로 옮길 수 있는 플로팅 버튼을 유지합니다.
- 하이라이트가 스크린샷에 포함돼도 해당 테두리 잉크만 인식 전에 보정합니다. 계속 깜빡이도록 숨기거나 재표시하지 않습니다.
- 화면에 보이는 최대 3개 조각의 **모든 순서**를 제한된 빔 탐색으로 비교합니다. 동일 상태 제거, 서로 다른 배치 순서의 후보 보호, 시간 예산이 부족할 때 전체 손패 배치 가능성 확인을 사용합니다.
- 즉시 점수, 콤보 유지, 3×3 공간, 가로·세로 5칸, 2×3·3×2 공간, 빈칸 고립과 줄 채우기 기회를 함께 평가합니다.
- 사용자 수동 배치가 추천과 달라도 화면에 보이는 **실제 소모 조각과 보드 전후 상태**를 확인해 콤보를 추적합니다. 관측이 불확실하면 콤보를 임의로 늘리지 않습니다.
- **현재 손패 전체를 배치하는 경로가 확인되지 않으면 안전한 수순인 것처럼 하이라이트하지 않습니다.**

## 점수 계산과 한계

동시 가로/세로 완성은 동일한 수에서 함께 삭제됩니다. 기본 점수 목적식은 Android Classic 10.8.1의 조사된 비변형 점수(줄 개수별 계수와 콤보)에 근거합니다. 다른 앱 버전·이벤트 규칙은 다를 수 있습니다. 실제로 다음에 나올 조각을 알 수 없으므로 가능한 모든 미래 손패에 대한 게임 오버 방지나 절대 최고 점수는 보장되지 않습니다.

이 버전은 **자동 플레이가 아닌 고득점 의사결정 보조**입니다. 실제 사용자 기기에서 개선된 점수/생존율이 객관적으로 검증된 것은 아닙니다.

화면은 로컬 기기에서만 분석합니다. 인터넷, 루트, 파일 저장소 권한을 사용하지 않습니다.

## 개발 및 검증

- JDK 17, Android SDK 35, Gradle 8.9
- `bash tools/check-core.sh`: 수치 계산, 랜덤 시뮬레이션, 실제/합성 화면 인식, 하이라이트 보정, 콤보 추적 회귀 검사
- `gradle :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug`
- APK의 `SOURCE_COMMIT.txt`, SHA256, 서명 및 권한 검증 파일은 빌드 아티팩트에 포함됩니다.

실제 게임 조작은 수동으로 하고, 실기기 화면에서 추천 위치를 확인하세요.
