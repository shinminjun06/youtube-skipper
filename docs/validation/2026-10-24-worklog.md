# 검증 기록

기준: blockblast-auto-build / 3b194f0eb7d05301e0c8ebba49ff524eea2cd243 (첨부 APK 0.3, versionCode 3).

- 원본 소스의 블록 차원 반올림 +1, 빈 영역을 집을 수 있는 bbox 중앙, 고정 Y 보정, 판/블록 개수만 비교하는 완료 처리를 확인하고 교체했다.
- RED→GREEN: 원본 스크린샷 격자/3개 모양; 동시 가로·세로 삭제와 부분 배치; 미지의 드래그 오프셋과 정확한 설치 확인; RGBA 패딩; 미지원 색과 모호한 보관함.
- 772 core checks 통과. 고정 seed 시뮬레이션: 합법 배치 360회, 줄 삭제 164개. 실제 게임 점수 측정이나 기존 앱 대비 점수 향상 증거는 아니다.
- 첫 Actions 빌드와 Kotlin 제어 연결 빌드는 성공했다.
- Android 컴파일·lint 성공 뒤, 첫 native 실행은 UTP 설치 이후 접근성 연결 누락으로 실패했다. 테스트 안에서 연결하도록 수정했다.
- 다음 native 실행은 테스트용 Activity의 DecorView 초기화 순서로 실패했다. 시스템 바 숨김을 setContentView 뒤로 이동했다.
- 별도 읽기 전용 리뷰에서 정지 시 마지막 UP 취소, 낮은 색 대비의 빈칸 오인식, 불확실한 보관함과 빈 보관함 구분 문제가 제기됐다. 색/보관함 회귀 테스트를 추가하고 수정했다. 정지 중 마지막 UP과 앱 전환 회귀 테스트를 추가했다.

## 판단한 범위

- 기술 선택과 중간 실행은 사용자가 위임했으므로 별도 선택 질문 없이 진행했다.
- 어두운/가려진 모양은 추측해서 조작하지 않고 멈춘다. 지원 범위가 좁아질 수 있으나 잘못된 연속 터치를 피한다.
- 실제 Block Blast의 떠오름/고스트/애니메이션, 실기기 성공과 고득점은 테스트 판만으로 판단하지 않는다.
- APK와 최종 소스 일치는 Actions artifact 안의 SOURCE_COMMIT.txt로 기록한다.
